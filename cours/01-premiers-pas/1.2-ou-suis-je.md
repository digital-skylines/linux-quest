## 📖 Ce qu'il faut savoir

Sous Linux, tous les fichiers sont rangés dans **une seule arborescence**, comme un arbre à l'envers. Tout en haut se trouve la **racine**, notée `/`. Tous les dossiers partent de là. Il n'y a pas de `C:` ou de `D:` comme sous Windows.

À tout moment, le terminal est « placé » dans un dossier : c'est le **dossier courant**. Quand tu te connectes, tu arrives dans ton **dossier personnel** (*home*) : `/home/andre`. Dans l'invite, il est abrégé en `~`.

Deux commandes pour s'y retrouver :

- `pwd` (*print working directory*) : affiche le chemin complet du dossier courant.
- `ls` (*list*) : affiche le contenu d'un dossier. Sans rien d'autre, celui du dossier courant. Suivi d'un chemin, celui de ce dossier : `ls /etc`.

Les **options** modifient le comportement d'une commande. Elles commencent par un tiret :

| Option | Effet |
|---|---|
| `ls -l` | affichage détaillé, un élément par ligne (*long*) |
| `ls -a` | affiche aussi les fichiers **cachés** (*all*) |
| `ls -h` | tailles lisibles (K, M, G) au lieu d'octets, à utiliser avec `-l` (*human*) |

Les options se combinent : `ls -l -a -h` s'écrit aussi `ls -lah`.

Un fichier **caché** est simplement un fichier dont le nom commence par un point, comme `.bashrc`. Ce sont souvent des fichiers de réglages, qu'on cache pour ne pas encombrer l'affichage.

## 🛠️ Pratique

1. Connecte-toi en SSH, puis tape `pwd`.
2. Tape `ls`. Ton dossier personnel est sans doute vide, ou presque.
3. Tape `ls -a`. Observe ce qui apparaît.
4. Affiche le contenu de la racine : `ls /`
5. Affiche le contenu de `/etc` en mode détaillé : `ls -l /etc`
   Dans chaque ligne, repère :
   - le **premier caractère** : `d` pour un dossier (*directory*), `-` pour un fichier ;
   - la **taille** ;
   - la **date** de dernière modification ;
   - le **nom**, à la fin.

   (Les lettres `rwx` du début sont les droits, vus au chapitre 6.)
6. Recommence avec `ls -lh /etc` et compare l'affichage des tailles.
7. 🧩 **À toi de jouer** : affiche **tout** le contenu de ton dossier personnel, fichiers cachés compris, en mode détaillé et avec des tailles lisibles.
