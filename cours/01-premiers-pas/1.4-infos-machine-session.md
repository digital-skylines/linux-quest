# Session 1.4 · Infos sur la machine et la session

🎯 **Objectif** : à la fin de cette session, je sais obtenir les informations de base sur ma machine, nettoyer mon écran et quitter proprement une session.

## 📖 Ce qu'il faut savoir

Quelques commandes simples pour savoir où on en est :

| Commande | Rôle |
|---|---|
| `date` | affiche la date, l'heure et le fuseau horaire |
| `uname` | affiche des informations sur le système (*Unix name*) |
| `clear` | efface l'écran du terminal (rien n'est supprimé, l'affichage est juste vidé) |
| `exit` | ferme la session en cours |

`uname` seul affiche juste `Linux`. Ses options donnent plus de détails :

| Option | Affiche |
|---|---|
| `-s` | le nom du noyau (*kernel*), c'est-à-dire le cœur du système : `Linux` |
| `-n` | le nom de la machine (comme `hostname`) |
| `-r` | la version du noyau |
| `-m` | le type de processeur (son architecture) |
| `-a` | tout à la fois |

**À propos de `exit`** : il ferme le *shell*, le programme qui lit et exécute les commandes que tu tapes. En SSH, la connexion se termine et tu retrouves le terminal de ton PC. La VM, elle, continue de tourner.

## 🛠️ Pratique

1. Tape `date`. Repère le jour, l'heure et le fuseau horaire.
2. Tape `uname`, puis `uname -r`, puis `uname -m`.
3. Tape `uname -a`. Retrouve dans cette ligne les informations des commandes précédentes.
4. Tape quelques commandes pour remplir l'écran, puis `clear`.
5. Tape `exit`. Observe où tu te retrouves.
6. Reconnecte-toi en SSH.
7. 🧩 **À toi de jouer** : affiche **en une seule commande** le nom de la machine et la version du noyau, et seulement ces deux informations.
